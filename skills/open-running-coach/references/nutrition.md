# 饮食、饮水与运动补给

目标是用食物支持训练与恢复，不是从手表热量开食谱处方。先看活动时长/强度、下一课间隔、平常饮食与胃肠耐受；需要按体重计算时才问体重。过敏、饮食偏好、携带条件及明确疾病限制会改变建议，已有信息不用重问。

以下为健康成人的参考，按情况缩放；未成年人、孕期或需医学饮食管理者不直接套成人定量。没有体重或摄入记录，不输出精确每日热量、能量缺口或营养缺乏诊断。手表消耗不等于需要额外吃掉同等热量，也不能成为少吃的理由。

## 先回答要不要额外补给

| 情况 | 碳水与食物安排 |
| --- | --- |
| 正常进食后的短时轻松活动，例如30—45分钟 | 通常无需额外能量胶；正常餐食及按需求饮水即可。空腹、饥饿、特殊医疗情况另议 |
| 持续45—75分钟较高强度 | 结合活动前是否进食与目标，少量易消化碳水可能有用；不机械要求30—60g/小时 |
| 持续约1—2.5小时的耐力运动 | 30—60g碳水/小时可作为适用人群的尝试范围；结合强度、耐受及既往经验从可耐受量试行 |
| 超过约2.5—3小时且需求较高的耐力活动 | 经过练习的运动者可考虑更高摄入，常见指南上限至90g/小时，超过60g/小时通常需混合糖源；不是新人或一般徒步者的默认目标 |
| 低至中等强度长徒步、连续多日 | 按行程安排规律小食与正餐，结合爬升、负重、全天供能和补给机会；不能把休闲长走照搬比赛高碳水方案 |

表中量是**碳水克数，不是食物总重**。饮料、胶、饭团、水果和正餐中的碳水要合计，不能重复计算。给出按时间的小份安排和普通食物替代；不要求固定品牌。食品成分优先看包装，估算时标明近似及份量。长途携带按全部行程和合理延误余量考虑；没有路线条件时不捏造补给点。

## 运动前后与日常吃什么

- **运动前**：正常正餐可安排在活动前约2—4小时，赶时间可选自己耐受的小份点心。易胃胀者临近活动避免一次大量高脂/高纤维食物；比赛日不首次试新品。具体时机是试行安排，不保证所有人耐受。
- **日常**：每餐含主食、蛋白食物、蔬菜水果，保留合理脂肪；长课/质量课日根据饥饿、训练量与既有饮食增加主食和点心，不以减重优先挤压恢复。没有膳食记录时先提可执行的改动，不编造“你缺蛋白”。
- **运动后**：以正常一餐补充主食与蛋白；距离正餐较久时先吃点心，如牛奶/适合自己的豆制品配面包或其他主食，再正常吃饭。奶制品不耐受/过敏时替换；各食品蛋白含量并不相等。
- **蛋白定量（确有需要时）**：AIS对训练量较大的成人提供每日约1.2—1.6g/kg的参考，分散进食，单次约0.3—0.4g/kg；不是要求所有休闲用户必须称重。说明采用范围和原因，不自动选上限。没有体重时用餐食结构/可核对的包装份量。
- **短间隔再训练**：若数小时内还有重要训练，优先及时补充碳水、蛋白和液体，并进一步查证适用的快速恢复方案。不能把竞技快速恢复配额套给一天一次轻松活动的人，也不营造错过30分钟就无效的焦虑。

例：若活动方案适合约40g碳水/小时，虚构标签显示某饮料每500mL含20g、某小食每份20g，则两者合计40g。**这不是必须每小时喝500mL的饮水要求**；液体需求较低时调整食物来源，不能为了吃够糖强灌饮料。

## 饮水与电解质

依据天气、汗量、时长、补水机会、口渴与耐受调整。不从汗多、白色盐渍或截图心率推算精确汗钠，也不为所有人开固定每小时饮水/盐丸剂量。普通短课可按口渴补水；长时间/炎热环境要预先安排可用水源和携带量，并在活动中调整，不等到明显不适才决定。

需要细化且用户能测量时，可用相近衣着和环境的运动前后体重、饮水量与排尿量粗估：

`汗率(L/h) ≈ [运动前体重(kg) − 运动后体重(kg) + 饮水(L) − 排尿(L)] ÷ 时长(h)`。

长途进食、湿衣物等会干扰，单次测量不是精确处方，也不要求把汗液损失全部强行喝回。避免运动中因过量饮水增重；运动饮料也可能喝过量。长时间大量出汗可结合普通含盐食物或合适饮料，按条件说明，不把补盐当作可以无限喝水的保护措施。

## 什么时候谈补充剂

食物优先。能量胶和运动饮料是便携补给选项；蛋白粉仅在普通食物不方便满足需求时可作为可选方案。不能默认每个人需要BCAA、肌酸、铁、镁或维生素，也不能根据疲劳、心率或单张图诊断缺铁并推荐剂量。疑似长期摄入不足、反复疲劳、月经改变或其他相关问题时，建议合格营养/医疗人员评估，不自行开补剂疗程。比赛使用者选择经过独立批次检测的产品，检测仍不消除所有风险。

## 给使用者的输出

先说本次需不需要额外补给，再给1—3项最有用的动作。详细方案可用“时间/情景—食物及份量—估计碳水或蛋白—可替代选择—调整条件”的小表，说明计算依据。恢复与下一次训练建议要一致；不一边安排休息，一边套用高负荷日大剂量补给。
