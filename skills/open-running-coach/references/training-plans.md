# 训练计划与调整规则

本文件约束宿主AI怎样结合数据与主动提问生成、解释和调整计划，不是某位用户的训练处方，也不表示已有独立训练计划引擎或已验证训练效果。数据工具负责其实际支持的汇总；主动提问按intake参考、恢复按recovery参考执行。

## 1. 面向谁、解决什么问题

面向使用不同运动App、具备不同跑步经验、训练时间和目标的个人使用者。读取可用记录并补充必要信息，生成适合当前阶段、可以理解和执行的训练计划。不能将项目作者的PB、海拔、偏好、周跑量或伤病经历写成默认用户参数。

用户以提升成绩为目标时，应提供能够产生适应的训练和明确进阶路径。健康与恢复帮助训练持续执行，不能成为无依据地长期压低训练剂量的理由。已有基础、近期承受稳定、当前无不适者，不自动套用初学者或恢复周方案；对健康、维持或兴趣目标，则尊重其本人的优先级。

### 对不同用户选择训练方向

| 用户目标与当前情况 | 计划方向 | 需要呈现的进展 |
| --- | --- | --- |
| 想提升成绩，已有基础、承受稳定、当前无不适 | 依本人的能力、目标距离和日程安排适量质量课及发展性有氧 | 关键刺激、配速依据、上调条件和复核；不用他人的跑量或强度作默认 |
| 想提升成绩，但新手或停训后回归 | 从当前能承受的剂量建立连续性，逐步加入合适刺激 | 明确从起点走向目标的步骤与条件，不长期只写维持；不直接复制成熟跑者的课 |
| 明确只想维持体能、健康或兴趣 | 在本人日程和偏好内保持所需运动，适当变化可选 | 以持续性、可执行性和维持表现复核，不强制PB目标或自动增加强度 |
| 仍希望提高，但出现不适或恢复异常 | 调整近期课程并视情况建议评估，保留原目标供后续重新评估 | 写清近期替换、复核及回到发展性训练的条件，不把症状当作可忽略的代价 |
| 未明确目标或多个目标冲突 | 先询问优先级及可接受投入，再决定阶段和剂量 | 不默认所有人只求维持，也不默认所有人接受高强度 |

比较不同使用者时，分别使用其近期记录和反馈。开源作者的一次训练、海拔、PB或偏好不构成其他人的能力标尺。成绩导向意味着刺激有效且可持续，不等于追求最高强度；维持导向也不等于所有人都必须使用同一低剂量。

## 2. 个体信息收集

| 信息 | 示例字段 | 用途与处理规则 |
| --- | --- | --- |
| 基本情况 | 年龄段、跑龄、当前运动限制、近期不适 | 根据实际需要询问，不收集与计划无关的身份信息；不生成疾病诊断 |
| 当前训练 | 最近4—8周的实际跑量、训练天数、时长、最长跑、强度课和其他运动 | 区分源数据覆盖与实际训练；缺记录不等于未训练 |
| 当前能力 | 近期测试/比赛距离、成绩、日期、海拔、场地、测量方式和是否全力 | 保留历史PB与当前能力的区别；不把短距离或过期成绩直接视为当前长距离能力 |
| 恢复与体感 | 疲劳、疼痛、睡眠、实际可取得的HRV/静息心率等 | 使用个人趋势及主观反馈，不依赖单一设备分数 |
| 目标 | 目标距离、目标成绩、日期、完赛/提升/PB等优先级 | 评估现有信息是否足以支持目标；说明不确定性，不保证达成 |
| 可执行条件 | 每周训练天数、单次时间、场地、力量器械、其他运动、偏好 | 计划首先能放进使用者的实际日程；未提供时列明暂定假设 |

已经能从授权数据和对话确认的内容，不重复询问。只补问影响决策的缺项。信息不足时可给条件性草案，不能靠填充虚假参数生成精确配速。

首次计划按[intake访谈](intake.md)分轮了解：目标与期限、近期能力和承受量、当前恢复以及实际可训练日期/单次时长。关键答案未取得前可以解释数据与阶段方向，暂不输出依赖假设的完整个体化日历；不要先默认每周五天或没有疼痛，再在计划末尾询问。用户明确只要暂定草案时标明假设，仍不能据此给强度训练许可。

用户要求加长、加快或把休息替换成跑步时，先澄清具体想改什么、为什么及近期反应，再决定课程和剂量。询问所得时间上限、其他运动和偏好应直接反映到日历，不仅在末尾作为提示。

## 3. 训练类型库

训练类型库定义可调用的课程，不要求每个人每周完成所有类型。

| 课程类型 | 设计目的 | 应输出的内容 |
| --- | --- | --- |
| 恢复跑 | 在适当阶段安排低负担活动 | 时间或距离、轻松程度、可替换为休息的条件 |
| 基础有氧跑 | 积累可持续的有氧训练 | 时长/距离、个体参考配速、交谈能力、强度范围 |
| 较长有氧耐力跑 | 延长舒适强度下的持续运动时间 | 相对个人近期最长跑的安排依据、配速/强度和补给说明（适用时） |
| 稳态跑 | 在计划需要时提供受控、持续的中等强度训练 | 与轻松跑、阈值跑的区别、持续时间和强度边界 |
| 阈值训练 | 安排接近个体阈值的持续跑或分段训练 | 阈值依据、参考范围、持续/分段时间、恢复；无可靠依据时标为待校准，不能伪称已测阈值 |
| 间歇训练 | 围绕当前能力和目标距离安排分段刺激 | 分段距离/时间、重复次数、每组用时、恢复方式、训练目的和停止条件 |
| 比赛配速练习 | 熟悉适当的目标赛事节奏 | 目标与当前能力是否相容、分段结构；目标配速不自动等于所有质量课配速 |
| 放松加速/短坡练习 | 需要时安排动作节奏与速度练习 | 方式、时间/距离、恢复、动作要求；短时练习避免过度依赖GPS瞬时配速 |
| 力量与稳定训练 | 支持跑步所需力量与控制能力 | 动作、组数、次数/时长、休息、器械、动作要点、常见错误、可靠示范和替代动作 |
| 交叉训练与休息 | 根据条件调整整体训练负担 | 活动形式、时间/强度、替换关系；其他运动不能被当成无负荷的休息 |

“轻松”描述强度，“基础有氧/耐力”描述目的和持续结构，标签允许重叠。不要为了课程看起来丰富而堆叠高强度；也不能把没有阶段说明的几次轻松跑宣传成完整的专项训练体系。

## 4. 配速与强度校准

1. 列出依据：近期成绩/测试、已验证的个体阈值（如有）、训练记录、体感和环境。
2. 区分实测、设备估计、模型估计和暂定参考。缺少当前能力信息时，给出明确的不确定性与补充测试/信息路径。
3. 条件允许时给配速范围；操场训练另给每圈/每组用时。热身、放松与组间恢复也需说明。
4. 同时给主观强度/交谈提示；心率只在测量可信且个体区间有依据时作为辅助。不同来源的不可信心率不能被平均后继续用于处方。
5. 风、温度、海拔、坡度和路面影响执行，允许按体感调整。不同品牌专有恢复评分不直接互换。
6. 不将某位使用者的配速设置成全体默认值；不把目标成绩直接用作当前训练能力；配速计算与单位换算应可复核。

## 5. 计划组织

- 根据目标、训练历史与可用时间确定当前阶段：入门适应、基础、专项、赛前减量或恢复衔接。阶段不是每个人必须按固定周数走完的流水线。
- 结合每周可训练天数、近期承受情况和其他运动选择课程。给出质量课与恢复的安排理由，不使用不加条件的固定强度比例或跑量增长公式。
- 首版输出未来7天可执行计划，附后续阶段方向。多周方案可作为后续扩展，不能把当前草案宣称为已验证完整周期。
- 每周说明总量、质量课数量、力量训练次数和与近期实际训练的变化。标记假设，不把计划当作已经完成的记录。
- 目标信息不足或明显不匹配时，说明需要校准的内容，提供可讨论的调整方向，而不是给出保证达标的处方。

## 6. 每节课输出结构

| 字段 | 要求 |
| --- | --- |
| 日期与类型 | 例如基础有氧、阈值或间歇；标明所在计划阶段 |
| 目的 | 用一句话解释为什么安排、与目标有什么关系 |
| 热身 | 时间/距离、参考强度、需要的熟悉动作 |
| 主训练 | 距离/时间、组数、配速/每组用时、辅助体感和恢复 |
| 放松 | 时间/方式 |
| 力量附件 | 需要时列具体动作、剂量、示范与替代，不只写“做力量” |
| 调整条件 | 时间不足、天气变化、疲劳、症状或未完成时如何处理 |
| 反馈项 | 实际完成、吃力程度、训练中不适和次日反应 |

## 7. 训练反馈闭环

读取实际完成记录和用户体感，识别完成量、执行强度与计划的差别；确认差别是否来自暂停、环境、记录误差或临时安排，再决定保持、减量、替换或进阶。不能仅因某次配速快就自动提高整周强度，也不能把一次未完成解释为能力下降。

反馈闭环必须同时允许进阶和减量。课程长期明显低于当前能力、按预期完成且恢复良好时，明确上调哪一个变量及其用途。未取得后续恢复反馈时可给条件性进阶，不宣称已经适应；不把每次顺利完成都解释成“继续保守即可”。

## 8. 验证与对外标注

当前状态：**已收录为宿主AI的计划生成规则；未实现独立计划引擎，新增行为与训练效果仍待独立体验和验证**。

至少用以下虚构场景检查计划是否随输入变化：初学者、每周只能跑3天者、有规律训练并希望提高者、刚完成长距离者、不同海拔/场地者、缺少近期成绩者、不可信心率或重复记录者、无法使用健身房者。

检查重点：目标与训练类型是否相符，配速是否有依据，训练总量与单课结构能否复核，是否安排恢复，力量动作是否能执行，缺信息时是否标注限制，后续反馈是否真实改变安排。通过生成检查不等于证明训练效果；真实用户体验与长期效果应分别说明，不采用作者一人的体验替代全部人群验证。

## 9. 计划真正发生调整

一周计划将徒步、力量和其他活动放进同一日程，分别标明负担，不换算成虚构的等效跑量。长徒步或下坡后的恢复可能推迟质量课；调整时直接写出原课、新课和原因，不能保留原计划再附“注意休息”。质量课与长课如何间隔需结合个人既往承受情况，不强制固定48小时或统一强度课数量。

可用0—10主观吃力程度辅助交流：轻松有氧常接近2—4、可说完整句子；较吃力的持续训练不能冒充轻松跑。量表只是参考，个体与运动类型存在差异，不能由此宣称测出乳酸阈值。阈值或间歇配速需当前能力依据，缺少时主动询问近期测试或可比训练，不以目标PB反算处方。

力量训练的初次安排优先熟悉、可控的少量动作，可提供2—3个动作、各1—2组的起步示例并标为试行量，随后按经验/器械调整；不在新增长课的同时默认高剂量力量。疼痛日不安排“矫正”伤处的陌生动作。示范链接必须实际核对，无法核对时提供清楚动作要点并说明尚未验证链接，不捏造视频地址。

## 10. 成绩导向的训练刺激与进阶

### 先找到限制，再选择刺激

结合近期可比表现与体感，判断当前更需要发展持续有氧、阈值附近的受控输出、目标距离节奏、较快配速下的耐受或动作力量。证据不足时说明可能性并通过后续课校准，不能由一张概要诊断出唯一短板。关键课要说明与目标成绩的关系，不用增加课程名称代替有效训练。

有基础且恢复稳定的用户可以在适用阶段安排质量课；次数和剂量由已有训练结构、可用天数和承受情况决定，不设所有人统一的“每周最多一课”或固定强度百分比。阈值、间歇和长有氧按目标选择，不能要求每周凑齐。仅有维持或恢复安排时，解释它服务哪个阶段、何时重新进入发展性训练。

### 让进阶可执行

| 变量 | 适用进阶 | 复核重点 |
| --- | --- | --- |
| 有氧总量/单课持续时间 | 在可承受范围内延长熟悉训练，或调整频次分配 | 下一课质量、持续疲劳、局部反应及日程是否允许 |
| 质量课有效量 | 增加一组或延长工作段，先保持已校准的配速 | 各组是否稳定、末组用力与动作、次日反应 |
| 配速/相对强度 | 相同结构持续完成得比预期轻松时，适度加快并说明依据 | 是否从受控训练变成测试；心率可靠性及环境变化 |
| 恢复间隔/密度 | 仅在符合课程目的时缩短恢复，其他主要变量尽量稳定 | 总体用力是否超出计划、后组是否明显失控 |

优先改变一个主要变量，避免同时明显增加频次、里程和速度；没有适合所有人的固定增长公式。说明具体上调条件和未达到条件时保留的剂量。不能把无痛视为可无限加量，也不能因为无法保证零风险就不给合理训练刺激。

### 校准基础跑，识别渐进部分

基础有氧可以覆盖不同的受控强度与持续结构，恢复跑有自己的低负担目的。依据稳定、可比的实际记录与完整交谈能力、主观用力及后续反应更新参考范围；无需为维持旧计划而坚持过慢的统一配速。

逐段越来越快、后程心率/用力增加的活动按渐进结构分析：全程平均不代表恒定强度，平均心率可能被前程拉低。更快末段可计为训练刺激，不能直接用于给全部日常跑定速。用户觉得余力充足是重要证据；同时核对分段、环境和心率可信度，不用单一信号定阈值或强度区间。

### 赛前与长期训练分别服务目标

赛前减量旨在减少累积疲劳并维持或发挥能力，通常可保留少量熟悉强度，调整总量与重复数。它不代表长期只练维持；也不因距比赛近就固定取消全部质量课。根据距离、近期负荷、训练经验与反应设计，不能在最后几天同时提高多项负荷来弥补缺课。

研究范围供维护判断，不直接生成个人处方：[跑者10周训练强度分配随机试验](https://pubmed.ncbi.nlm.nih.gov/23752040/)比较不同结构，不能证明唯一通用比例；[2023赛前减量系统综述](https://pubmed.ncbi.nlm.nih.gov/37163550/)支持减量并保留适用强度，混合项目结果不能机械套用到每位短距离跑者。2026-11-12核对。
