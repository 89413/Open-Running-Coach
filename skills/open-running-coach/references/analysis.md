# 数据分析规则

## 单次跑步

确认活动归属、运动类型和日期；Garmin工具的距离为米、时长为秒，截图及其他文件按实际标签和已核实的映射解释，单位不明确时先核对。区分设备计时时间、经过时间、移动时间，平均配速使用明确的分母。平均配速=计时秒数÷距离公里数；不能把平均心率当成阈值，也不能从最大观测心率推断个体最大心率。

分圈采用源文件实际圈长和计时。圈长不同或最后不足一公里时，先归一配速；分析前后程变化要考虑暂停、地形、风、路线、主动变速和测量质量。步频注意是总步数/分钟还是单侧步频。源字段不明确就说明，不能擅自翻倍。

只在存在可信、足够连续的逐点数据且条件可比时考虑心率漂移等分析；概要或不同强度分圈不支持标准化漂移结论。仅有截图时核对可见数字及单位，不补造不可见数据。

## 训练趋势

使用实际日期与完整区间，计算跑量、总计时、训练天数和单次长距离占比。分段活动不必等于多次独立训练。跑步与其他运动分开统计，同时考虑其他运动负荷。缺记录不表示没有训练。

不直接平均各活动配速：汇总配速使用总时间÷总距离。汇总心率若有用，注明按有效计时时长加权，并只纳入可信记录。不将不同海拔、运动类型、比赛和恢复跑的混合配速差异直接解释为能力变化。

识别重复与借表记录后再汇总。保留原始活动ID、源App和实际记录设备（如果能获得）；跨源疑似重复不能只看App ID，应核对时间、时长、距离等，并区分重新导入与另外一次训练。

## 恢复线索

按实际日期核对睡眠、夜间/滚动HRV、个体基线、静息心率及设备实际提供的其他指标。区分夜间值、七日均值、全天最大值与实时值；覆盖范围不足时明确说明。

Garmin健康工具可能返回重叠批次：按请求日期过滤，再按数据集与日期去重；保留更新较新的有效记录，不用缺失值覆盖已有有效值。健康数据集份数不是覆盖天数。

不同品牌的专有训练负荷、睡眠/恢复分数不可直接拼成同一量表；更换设备或算法后检查基线。体感、疼痛及训练后反应需要独立考虑，手表状态不能判断局部肌腱已恢复。不可信心率也会影响依赖心率的训练效果/负荷指标，不能拿这些派生值反证心率可靠。

## 报告的最小内容

- 来源、实际日期、关键缺失和已应用的排除/可信度标记。
- 与当前问题最相关的表现与依据，避免堆砌全部指标。
- 训练/恢复建议及可观察的调整条件。
- 结论的限制，以及哪些新增信息会改变建议。

不强制生成文件；用户需要导出时使用Markdown或已有合适工具，注明文件位置。真实个人报告放在私有目录，不放进项目示例。

## 从记录走向教练决策

先辨认用户本次要解决的问题及活动目的：轻松积累、质量训练、测试、比赛或徒步。没有目的时给出暂定解释，不因配速更快就评价为更好。优先解释影响下一步安排的内容：

| 判断对象 | 有依据时分析 | 相应决策 |
| --- | --- | --- |
| 执行与节奏 | 计划与实际；分段、暂停、地形、后程主动加速或非主动掉速 | 是否保留原计划、降低下一课负担或调整起跑节奏 |
| 心肺与局部负担 | 可信心率、呼吸/交谈、主观吃力程度、局部肌肉反应分别看 | 呼吸轻松不等于肌腱已恢复；不可信心率的派生评分也降权 |
| 耐力与补给 | 同条件后段变化、持续时长、进食饮水及胃肠反馈 | 先核对原因再调整持续时间或补给，不能由掉速直接诊断缺糖/脱水 |
| 近期结构 | 已知区间的总时长、频次、长课与质量课，以及徒步/力量 | 判断本次是否是新增刺激、是否挤占恢复；缺记录不直接说跑量激增 |
| 个体恢复 | 当前体感与个人睡眠/HRV/静息心率趋势，而非人群阈值 | 使用恢复参考安排下一步；单个评分不能放行或否决训练 |

每个关键判断尽量组成“观察 → 解释与可信度 → 行动”。解释竞争时指出什么信息能区分；只有概要时仍可评价已知的时间、距离、目的与反馈，不把空白填成逐公里分析。

综合报告的参考顺序：

1. 简要结论和证据范围：完成了什么、最影响下一步的发现。
2. 关键表现与个人背景：用最相关的2—4项证据解释，不逐项复述表盘。
3. 今天/明天的恢复和下一课：具体剂量、执行感觉、替代与停止条件，见恢复参考。
4. 本次确有需要的吃喝安排：普通短课可直接说明正常餐食即可，不推销补剂。
5. 下一次反馈：询问少量会改变计划的事项，例如次晨下楼感受、下一课相同强度的体感。

简短事实问答不强套完整报告；“全面”意味着覆盖有关决策，不意味着篇幅越长越好。不能从心率、配速或体感估计诊断贫血、缺氧、过度训练；需要时说明可能性和专业评估路径。

## 连续使用

先复用本次可读对话和授权记录中的目标、日程与限制。对曾经给出的计划核对实际完成，再说明保留/替换哪一课以及原因。连续缺觉、未完成课或局部不适应改变后续安排，不能只是附一句提醒。

没有持久档案时明确使用范围，不声称后台跟踪、自动记住跨聊天信息或自动同步。用户需要跨会话衔接时可提供可复制摘要：目标、最近覆盖区间、排除记录、当前周安排、强度依据、症状与下次复核项；实际写入私有档案须按用户要求完成。
