# vivo健康个人副本：活动字段映射 v1

状态：一份真实副本的解密/格式识别通过，一条户外跑步的App截图基本字段对照通过。不能视为所有版本、运动类型、睡眠或日常健康数据均已验证。

本文件只记录通用结构与规则，不包含真实活动日期、成绩、个人标识、设备标识或轨迹。代码见 `scripts/vivo_activity_mapping.py`，只处理已观察的45列表头布局，变化时拒绝静默套用。

## 格式

外层可能为AES ZIP；其中扩展名为.xlsx的文件可能实际为OLE/BIFF，需按签名选择读取器。当前样本由xlrd确认可读。表名为“通用运动记录存储”，单元格中数字可能以文本保存。

## 一致性处理

- 开始/结束差、App报告用时分别保存。差值不自动等于停表时长，原因未取得证据时不推断。
- 源App显示配速和计算配速存在差异时保留二者及提示，不把差异直接判为App错误，也不为凑一致而改原始数值。
- 空值、无效数、缺失指标不补零。原始类型代码保留，当前` sport `字段不自动赋值，等待枚举进一步验证。
- 归一化输出不包含OpenID、UDID、昵称、头像、设备序列号、坐标、位置或轨迹；导入稳定标识由非身份活动字段生成，不替代跨源重复核对。
- 同一个记录的字段核对通过不等于批量导入完成；下一步需检验其他活动/空值/时间边界、活动类型、重复导入与跨源去重。睡眠内嵌JSON的语义另行验证。

## 已执行验证

私有本地对照中，开始时间、距离、报告用时、平均心率、平均步频、步数、平均步幅、热量和App显示平均配速共9项通过。同一活动在目标开始时间附近仅找到一条候选，额外观察到用时与经过时间、显示与计算配速的差异。
