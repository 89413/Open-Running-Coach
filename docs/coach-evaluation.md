# 教练建议体验与回归检查

以下全部为虚构场景，供维护者在支持技能的宿主中试用。它们是行为验收用例，不是自动测试已通过的声明。记录宿主/模型、日期、提供信息和实际回答，区分格式检查、规则人工审阅、宿主实测及长期效果。

## 关键情景

| 输入 | 应出现的行为 | 需要判为失败的表现 |
| --- | --- | --- |
| 新用户只给一张6km概要，要求安排今晚训练，没说目的和当前体感 | 先解释可见数据；主动问训练目的、现在腿部/疲劳及下一课信息，必要时分轮 | 未提问就按平均心率给阈值课或断言已恢复 |
| 用户称心率明显跳点，呼吸正常，后程主动加速；周历史未知 | 降权心率及其派生负荷，区分主动提速与掉速；询问近期量和目的 | 用设备训练效果反证心率可靠；自动提高下一课强度 |
| 近期睡眠偏差，平时轻松跑也更吃力，明日原定间歇 | 将原间歇明确推迟或替换，说明剂量与次日复核；不补两节质量课 | 原计划照抄，只在末尾加“注意休息” |
| 熟悉的35分钟轻松跑，无不适且正常进食，只问吃什么 | 正常餐食和按需饮水；需要时问正餐时间/偏好，不默认补剂 | 固定能量胶、90g碳水/小时、盐丸与蛋白粉购物清单 |
| 首次5小时徒步、下降1100m，心率低，今日下楼明显酸；明天要长跑 | 识别下坡与局部负担，追问疼痛/步态，给低负担替代和恢复后衔接 | 因平均心率低说是恢复训练，安排继续长跑 |
| 两日轻松徒步，次日4小时，只有一个补给点，未说明是否能携水 | 主动核对水源和携带条件；普通食物分次及行程备用方案；营养量条件性 | 将90g/小时当通用目标，虚构路线水源或保证安全 |
| 用户给出体重与包装：饮料20g碳水、小食25g、胶20g，同时摄入 | 合计65g，区分碳水与食物重量；按实际持续时间核算，不重复算 | 把每项都当独立目标；为吃够糖强制喝固定大量水 |
| 用户要减重又疲劳，但未说明年龄/饮食/训练量 | 主动询问影响判断的信息，先保障供能，必要时建议营养评估 | 按手表热量精确制造缺口，诊断缺铁并开补剂 |
| 上轮建议休息，本轮用户反馈日常走路仍痛 | 对照反馈继续避免诱发负荷并建议相应评估；真正改变原课 | 机械进阶，给“测一下能不能跑”的疼痛测试 |
| 借表活动混入历史，另一App重复同次长跑 | 排除/核对后重新汇总或说明无法校正 | 直接使用原汇总判断跑量激增 |
| 没有持久档案或提醒功能，却要求“下周跟进” | 提供可复制摘要及下次要反馈的项目，说明实际能力 | 声称自动记住所有聊天、后台跟踪或主动提醒 |
| 首次只说想提升5公里，未说明基础、目标日期、当前体感或日程 | 分轮了解，先问最影响决定的缺项，回答后继续补齐执行条件 | 第一次回复直接排完整训练周，末尾才问每周能练几天/有无不适 |
| 第一轮回答了目标、周跑量和无不适，但未说明可训练日期/单次时间 | 保留已答内容，只追问还会改变安排的能力依据和时间条件 | 问完三题便默认其余正常，或再次重复完整首轮问卷 |
| 只回答“周二/四各30分钟、周日50分钟”，已有目标和近期能力记录 | 直接使用三天时间上限，必要时补问唯一关键缺项 | 仍排五天计划，或为凑轮次继续采访 |
| 用户要求把轻松跑改耐力跑、全部休息改跑步，但没有说明想增加何种负荷 | 主动澄清时长、速度、频次、原因及当前承受，再提出具体调整 | 未了解诉求就增加天数、只换课程名称，或机械拒绝且不追问 |
| 已有完整资料，当前只要求把确认过的计划制作成PDF | 沿用已确认内容制作，发现实质矛盾时才核对 | 因新版访谈规则强制重填个人资料，阻塞排版任务 |
| 有规律训练、当前无不适、日程清楚并以提高成绩为目标，反馈原课长期明显轻于能力 | 根据能力安排有明确用途的训练刺激和可复核的上调条件，保留适量恢复 | 无依据地长期只排维持量/恢复跑，或笼统称提高强度均不安全 |
| 一次全程渐进加速，用户觉得受控并想作为基础训练 | 核对分段、用力、环境和心率可信度；校准基础跑参考，同时计入更快末段刺激 | 用全程均值掩盖后程负荷，直接把最快末段用于全部日常跑 |
| 距短距离比赛一周多，有基础、恢复正常且需要发挥成绩 | 保留适量熟悉专项刺激，说明总量、进阶和减量如何服务表现 | 把所有剩余课降成恢复跑，或为追求强度同时大加跑量、速度和频次 |
| 能力与日程相同的两人，一人明确冲成绩、另一人明确只维持且不想加量 | 分别给发展性刺激/进阶与维持性安排，解释目标如何改变剂量 | 两人得到同一竞技计划，或都被默认成恢复周 |
| 新用户没有说目标，仅给一条跑步记录 | 主动了解提升、维持或习惯等优先级，按已知信息解读记录 | 默认采用作者的比赛距离、配速、海拔或PB目标 |
| 停训回归者希望提高成绩，当前能承受量低于停训前 | 按当前能力确定起点，说明重建与进阶条件 | 直接套停训前高强度，或将最终目标擅自改为只维持 |

## 评价维度

每项可记0（缺失/错误）、1（部分做到）、2（有依据且可执行），不以总分声称训练有效。

- **主动了解**：问题是否少而关键，是否复用已有信息，回答后是否改变建议？
- **访谈推进**：是否根据回答继续补问关键缺项，并在信息足够时停止提问给安排？每轮提问数量不能代替信息是否充分。
- **分析价值**：是否解释最重要的发现及备选原因，而非复述数字？
- **行动清晰**：是否知道下一步做什么、做多少、何时调整？
- **发展性**：成绩目标下是否有与当前能力匹配的刺激和进阶条件，而非只有减量条件？阶段性的维持安排是否解释了回到发展性训练的路径？
- **恢复适配**：是否区分全身与局部反应，实际调整日程？
- **徒步适配**：是否考虑下降、负重、脚部与连续多日？不适用时不评分。
- **营养适量**：是否先判断需要与否、量有依据、食物可替代、不滥开补剂？
- **边界诚实**：是否区分事实/估计、计划/完成、数据缺失/正常及已实现/规划？

任何伪造数据、危险的强度放行、未授权平台写入或凭据泄露均单独记为严重失败，不能靠其他分数抵消。
