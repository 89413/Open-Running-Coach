# 数据分析规则

## 单次跑步

确认活动归属、运动类型和日期；Garmin工具的距离为米、时长为秒，截图及其他文件按实际标签和已核实的映射解释，单位不明确时先核对。区分设备计时时间、经过时间、移动时间，平均配速使用明确的分母。平均配速=计时秒数÷距离公里数；不能把平均心率当成阈值，也不能从最大观测心率推断个体最大心率。

分圈采用源文件实际圈长和计时。圈长不同或最后不足一公里时，先归一配速；分析前后程变化要考虑暂停、地形、风、路线、主动变速和测量质量。步频注意是总步数/分钟还是单侧步频。源字段不明确就说明，不能擅自翻倍。

只在存在可信、足够连续的逐点数据且条件可比时考虑心率漂移等分析；概要或不同强度分圈不支持标准化漂移结论。仅有截图时核对可见数字及单位，不补造不可见数据。

## 训练趋势

使用实际日期与完整区间，计算跑量、总计时、训练天数和单次长距离占比。分段活动不必等于多次独立训练。跑步与其他运动分开统计，同时考虑其他运动负荷。缺记录不表示没有训练。

不直接平均各活动配速：汇总配速使用总时间÷总距离。汇总心率若有用，注明按有效计时时长加权，并只纳入可信记录。不将不同海拔、运动类型、比赛和恢复跑的混合配速差异直接解释为能力变化。

识别重复与借表记录后再汇总。保留原始活动ID、源App和实际记录设备（如果能获得）；跨源疑似重复不能只看App ID，应核对时间、时长、距离等，并区分重新导入与另外一次训练。

## 恢复线索

按实际日期核对睡眠、夜间/滚动HRV、个体基线、静息心率及设备实际提供的其他指标。区分夜间值、七日均值、全天最大值与实时值；覆盖范围不足时明确说明。

Garmin健康工具可能返回重叠批次：按请求日期过滤，再按数据集与日期去重；保留更新较新的有效记录，不用缺失值覆盖已有有效值。健康数据集份数不是覆盖天数。

不同品牌的专有训练负荷、睡眠/恢复分数不可直接拼成同一量表；更换设备或算法后检查基线。体感、疼痛及训练后反应需要独立考虑，手表状态不能判断局部肌腱已恢复。不可信心率也会影响依赖心率的训练效果/负荷指标，不能拿这些派生值反证心率可靠。

## 报告的最小内容

- 来源、实际日期、关键缺失和已应用的排除/可信度标记。
- 与当前问题最相关的表现与依据，避免堆砌全部指标。
- 训练/恢复建议及可观察的调整条件。
- 结论的限制，以及哪些新增信息会改变建议。
