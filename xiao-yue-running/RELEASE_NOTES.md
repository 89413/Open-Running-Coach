# Open Running Coach v0.1.0-beta.1

首个公开预发布候选：Garmin个人数据连接与运动App截图分析技能。

## 当前功能

- 可选Garmin Personal API、本机DPAPI凭据、同步CLI、SQLite缓存与七个只读MCP工具。
- 运动截图的概要、分圈、可辨曲线与恢复线索分析。
- 结合个人能力、目标与体感生成训练计划、参考配速及力量训练建议。
- 技能安装和备份更新，MIT许可证。

## 本次补充的资料

- COROS官方入口与OAuth发现的无凭据验证结果；尚未完成真实账号授权、工具调用或运动数据核对。
- Strava官方OAuth/MCP的接入边界及使用限制。
- 统一接口、适配器、自动刷新、账号分区缓存与错误分类的实施方案。

## 当前限制

- 文档研究不等于代码实现；Strava/COROS适配器及每次分析自动联网刷新尚未实现。
- Garmin MCP读取本地缓存，须先完成同步；其他平台截图分析不等于平台自动同步。
- 新环境安装、不同账号/地区、各种截图版式及训练效果尚待独立用户验证。
- 当前Garmin连接代码面向Windows；截图技能取决于宿主图片理解能力。

5项Garmin虚构数据测试及2项安装器测试通过。请勿在Issues或提交中包含凭据、健康数据、真实截图或GPS。欢迎用虚构样本反馈问题。
